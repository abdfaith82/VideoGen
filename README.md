# VideoGen AI — مولّد فيديو طويل من النص والصور (أندرويد)

تطبيق Kotlin / Jetpack Compose يولّد فيديو طويلاً عبر سلسلة مشاهد قصيرة:

1. تكتب مشاهدك (أو تلصق سيناريو: كل سطر = مشهد) وتختار صورة بداية اختيارية.
2. يرسل التطبيق كل مشهد إلى **Space مجاني على Hugging Face** (واجهة Gradio).
3. بعد كل مشهد يستخرج **آخر إطار** ويستخدمه كصورة بداية للمشهد التالي (استمرارية بصرية).
4. يربط كل المقاطع على الجهاز بـ **Media3 Transformer** في ملف MP4 واحد، مع معاينة وحفظ في المعرض.

## ما يجب معرفته بصراحة

- التوليد الواقعي **لا يعمل على الهاتف نفسه**؛ يتم في السحابة عبر Spaces مجانية.
- المجاني له **حصص GPU** يومية وطوابير انتظار، وقد يتغير أي Space أو يتوقف. لذلك رابط الـ Space و`api_name` وقالب المدخلات **قابلة للتعديل من الإعدادات**.
- الإعداد الافتراضي (`kingnish-ltx-video-distilled`) لم أتحقق من أنه يعمل حالياً. إن فشل: افتح Space آخر يدعم نص/صورة إلى فيديو، ثم «Use via API» وانسخ الاسم وترتيب المدخلات إلى الإعدادات.
- «طويل» = عدة مقاطع (غالباً 2–5 ثوانٍ لكل مقطع) مربوطة معاً، وليس مقطعاً واحداً طويلاً.
- التوليد يعمل داخل التطبيق؛ أبقِ التطبيق مفتوحاً (الشاشة تبقى مضاءة تلقائياً أثناء التوليد).
- لم يُبنَ المشروع ولم يُختبر على جهاز؛ الحكم النهائي لتبويب Actions.

## قالب المدخلات

مصفوفة JSON بترتيب مدخلات الـ API. بدائل مدعومة: `{{prompt}}` `{{negative}}` `{{image}}` (يصبح `null` إن لم توجد صورة) `{{seed}}`.

مثال: `["{{prompt}}", {{image}}, null, null, 3]`

## البناء

الإصدارات: AGP 8.2.2 · Kotlin 1.9.22 · Compose compiler 1.5.8 · Compose BOM 2024.02.00 · Gradle 8.5 · JDK 17.

عبر GitHub Actions: ادفع إلى `main` ثم نزّل `VideoGen-debug-apk` من تبويب Actions.
محلياً: `gradle assembleDebug` (ثم `app/build/outputs/apk/debug/app-debug.apk`).
